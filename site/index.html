Confidence has boundaries

The result covers
the check we agree.

A clean result means no supported issues were found in the completed, valid checks. It does not prove every feature is correct or every user session is healthy.

  • Journey outcomes need explicit assertions and human review; automatic route visits are not functional acceptance tests.
  • Retention signals suggest where to investigate. A resource count alone does not prove the exact cause or fix.
  • This pilot excludes security testing, backend load testing, accessibility audits, full cross-browser testing, and continuous monitoring.
  • Blocked routes, failed measurements, and incomplete journeys are reported as limits rather than silently counted as success.
