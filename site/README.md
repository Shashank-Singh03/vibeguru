# Local commercial preview

Open `index.html` locally, or serve the repository root and visit `/site/` so the fixture-report link resolves to `/examples/sample-report.html`.

This is a dependency-free, responsive static landing page for the $300 founding pilot. It is not published. It includes no payment flow, account, API endpoint, tracking, or enquiry delivery service.

The form validates the required fields and creates `vibe-guru-enquiry.txt` using a browser Blob download. It explicitly states that nothing has been sent. The resulting brief is meant to be shared through an existing founder contact channel. A downloadable plain-text fallback is included for browsers with JavaScript disabled.

Before public use, the owner must review the offer, supply a real contact/booking channel, and check scheduling, billing, and access arrangements. Do not replace the download with a simulated “submitted” state. No credentials or customer information belong in the preview, sample report, or enquiry brief.

The sample-report link is `../examples/sample-report.html`; that file must be generated by the actual product reporter from the bundled intentionally broken fixture. Never present it as a customer case study.
