## What the buyer receives

Agreed coverage and run conditions; reviewed findings with reproduction/evidence; likely investigation actions; incomplete/blocked/invalid checks; and one comparable confirmation run when access and customer changes permit it within the cap. No guarantee that defects will exist or that all defects will be found.

Excluded: security, backend load, accessibility audit, comprehensive functional acceptance, full cross-browser coverage, continuous monitoring, scaling claims, and unlimited fix work.
